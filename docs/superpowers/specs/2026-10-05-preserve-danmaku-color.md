# 保留弹幕颜色开关

## 需求

用户反馈部分颜色的弹幕在快速移动时看不清。为通用弹幕插件增加一个「保留弹幕颜色」开关，让用户选择使用原始颜色或统一白色。

- 标题：`保留弹幕颜色`。
- 说明：`关闭后，弹幕统一显示为白色`。
- 选项：`开启` / `关闭`，默认 `开启`。
- 开启时保留各平台解析后的原始颜色；关闭时返回白色 `16777215`（`0xffffff`）。
- 不删除彩色弹幕，不新增 50% / 100% 彩色模式。
- 完整版、精简版均提供此选项，普通弹幕请求和切片请求均生效。

## 工程约定

- 配置名采用既有命名空间：`global.content.preserveDanmakuColor`；宿主传入字符串 `"true"` / `"false"`，内部使用 boolean。
- 缺失或非法配置回退为开启，兼容没有此字段的旧配置。
- 颜色仅在最终序列化 `CommentItem.p` 时转换，不修改抓取器、原始弹幕对象或缓存。
- 保留现有聚合键（模式、原始颜色、文本）及聚合次数；关闭开关不改变数量、文本、时间、模式、ID 和来源。
- 再次开启后恢复原色；后续请求未提供配置时恢复默认开启。
- 复用现有 Zod、Rstest 和 Rslib 工具链，不新增依赖。
- 扩展应用自己的配置 schema，不把展示偏好加入共享 `scraper-kit`。

## 验收

默认及开启返回原色，关闭返回白色；多源、滚动/顶部/底部弹幕均一致；空切片正常返回；切换配置不污染原始对象；不同原色的同文弹幕保持现有聚合行为。构建产物中的完整版、精简版均包含正确的开关元数据。

## 已确认决策

2026-10-05 用户在了解当前默认输出原色、缺省颜色补白及系统继承协议尚不明确后，明确回复「那就白色吧」。因此本次关闭开关统一白色，不依赖“跟随系统颜色”协议；默认开启仍保持现有原色行为。
